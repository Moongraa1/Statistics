# 🏆 CS2 Team Roster & Stats Tracker

Полноценное адаптивное веб-приложение для ведения и анализа статистики киберспортивной команды в **Counter-Strike 2**. Разработано на чистом стеке **HTML5, CSS3 и Vanilla JavaScript** без единой внешней зависимости — готово к мгновенному запуску локально или публикации на **GitHub Pages**.

## ⚡ Ключевые возможности

### 1. 🎨 Фирменный киберспортивный UI/UX (CS2 Dark Theme)
- Цветовая палитра: глубокий фон `#0b0e14`, панели `#151922`, оранжево-золотой акцент CS2 `#e4891b` и `#de9b35`.
- **Интеллектуальная цветовая индикация**:
  - Высокий K/D ($\ge 1.00$) подсвечивается зеленым (`#2ea44f`).
  - Низкий K/D ($< 1.00$) подсвечивается красным (`#f85149`).
  - **MVP команды** автоматически награждается сияющим золотым бейджем.
- **Адаптивность**: плавный скролл на мобильных устройствах, закрепленная первая колонка с никнеймом бойца для комфортного просмотра с телефона, крупные touch-friendly кнопки.

### 2. 📊 Общий дашборд команды
В режиме реального времени рассчитывает:
- Количество игроков в ростере и распределение ролей;
- Всего сыграно человеко-матчей и среднее число на бойца;
- **Командный K/D** (сумма фрагов команды к сумме смертей);
- Суммарные **Kills / Deaths / Assists** и показатель командного KDA;
- Сумма клатчей (1vX) и эйсов (5k);
- **MVP состава** — автоматический выбор лидера по эффективности.

### 3. 👥 Управление составом и интерактивная таблица
- **Добавление игрока** с выбором роли: *Снайпер (AWP)*, *Капитан (IGL)*, *Рифлер*, *Энтри-фрагер*, *Саппорт*.
- Защита от дубликатов никнеймов (регистронезависимая).
- **Прямой ввод и степперы** `+` / `-` для каждого показателя (Matches, Kills, Deaths, Assists, Clutches, Aces).
- Автоматически вычисляемые поля без возможности случайной поломки:
  - **K/D Ratio**: $\text{Kills} / \text{Deaths}$ (защита от деления на ноль при 0 смертей).
  - **KDA Ratio**: $(\text{Kills} + \text{Assists}) / \max(1, \text{Deaths})$.
  - **K/M (Kills per Match)**: среднее число фрагов за карту.
- **Интерактивная смена роли** прямо в таблице.
- **Переименование игрока** (двойной клик по никнейму).
- **Сортировка по клику** на заголовки любых колонок (по возрастанию / убыванию) с маркерами `▲`/`▼`.
- **Живой поиск** по никнейму и роли.
- **Flash-подсветка** измененных ячеек при редактировании.

### 4. 🎯 Быстрое внесение матча (Match Logger)
- Модальное окно быстрой фиксации только что сыгранной карты:
  - Выбор игрока из состава;
  - Выбор соревновательной карты (`de_mirage`, `de_inferno`, `de_nuke`, `de_dust2`, `de_anubis`, `de_ancient`, `de_vertigo`);
  - Результат: **Победа**, **Поражение**, **Ничья**;
  - Показатели за катку: Kills, Deaths, Assists, Clutches, Aces.
- **Автоматический учет**: при сохранении матча общая статистика игрока увеличивается, а катка заносится в «Историю последних матчей».
- **Откат матча**: при удалении записи из истории статистика игрока аккуратно возвращается назад без потери остальных данных.

### 5. 💾 Синхронизация и хранение данных
- Автоматическое сохранение всех изменений в `localStorage` браузера.
- **Экспорт JSON**: сохранение базы команды в `.json` для передачи тиммейтам или бэкапа.
- **Импорт JSON**: загрузка базы из файла с валидацией структуры и защитой от ошибок.
- **Переименование команды**: кликните на заголовок команды, чтобы дать ей свое название.
- **Демо-состав**: кнопка мгновенной загрузки примера готовой CS2 команды.
- **Полный сброс**: очистка базы с подтверждением через `confirm()`.

## 🚀 Как запустить проект

### Вариант 1. Локально
1. Просто откройте файл `index.html` в любом современном браузере (Chrome, Edge, Firefox, Safari, Opera).
2. Подключение к интернету не требуется — все шрифты, иконки (SVG) и скрипты встроены локально.

### Вариант 2. Развертывание на GitHub Pages (за 1 минуту)
1. Создайте репозиторий на GitHub (например, `cs2-roster-tracker`).
2. Загрузите файлы:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
3. В настройках репозитория перейдите в **Settings** ➔ **Pages**.
4. В разделе **Build and deployment** выберите источник **Deploy from a branch**, укажите ветку `main` (или `master`) и папку `/ (root)`, нажмите **Save**.
5. Через 30 секунд сайт станет доступен по адресу: `https://<ваш-логин>.github.io/<имя-репозитория>/`.
